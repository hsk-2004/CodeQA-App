# CodeQA-App

A RAG-based Code Q&A assistant built progressively across the AI DevOps hands-on activities. Given a question about a small sample codebase, the app retrieves relevant code chunks and uses Code Llama (via Ollama) to answer.

## Structure

- **[week1/](week1/)** — VM setup, static website, Git workflow fundamentals.
- **[week2/](week2/)** — Running Code Llama on the VM via Ollama.
- **[week3/](week3/)** — The application itself, built in 5 progressive exercises:
  - `exercise1_basic.py` — basic App → Ollama → Code Llama connection.
  - `exercise2_knowledge_base.py` — chunking + embeddings to build `knowledge_base.json`.
  - `exercise3_rag.py` — retrieval + RAG, with/without context comparison.
  - `services/` — App and Retrieval services split into independent FastAPI APIs (Exercise 4).
  - `docker-compose.yml`, `services/Dockerfile.*` — Dockerized services (Exercise 5).
  - `sample_codebase/` — the small sample codebase (`auth.py`, `payment.py`, `registration.py`) the app answers questions about.
- **[week4/](week4/)** — Multi-model evaluation and RAG analysis:
  - `questions.json` — 27-question evaluation set across 7 task categories.
  - `run_evaluation.py` — runs every question through the RAG pipeline against 3 models (`codellama:7b`, `starcoder2:3b`, `phi3:mini`), logging latency and token usage.
  - `results.json` — evaluation output (generated by running the script).

## Running it

See [week3/](week3/) for the core app (requires Ollama running locally with `codellama:7b` and `nomic-embed-text` pulled), and [week4/](week4/) for the evaluation suite (also requires `starcoder2:3b` and `phi3:mini`).
