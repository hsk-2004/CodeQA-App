# Week 1 — VM Setup, Static Website, and Git Workflow

This week's activity was completed on the virtual machine environment (VMware Workstation Pro, Ubuntu) and covered:

- Setting up and configuring the VM environment.
- Creating and hosting a simple static website on the VM.
- Connecting the hosted project to a GitHub repository.
- Making modifications to the site and pushing updates using the standard Git workflow (`git add` → `git commit` → `git push`).

This established the foundational Git + VM workflow used throughout the rest of this project (Weeks 2-4), including the same VM and the same GitHub repository (`hsk-2004/CodeQA-App`) used for the application built starting Week 3.
